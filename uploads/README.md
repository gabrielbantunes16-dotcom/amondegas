# Arquivos ZIP

Coloque nesta pasta os arquivos `.zip` que serão enviados ao repositório.

## Envio pelo GitHub

1. Abra a pasta `uploads` no GitHub.
2. Selecione **Add file → Upload files**.
3. Arraste o arquivo `.zip` para a área de envio.
4. Revise o nome e confirme em **Commit changes**.

## Cuidados

- O limite para um arquivo enviado diretamente ao GitHub é 100 MB.
- Para arquivos maiores, use Git LFS ou GitHub Releases.
- Não inclua senhas, tokens, chaves privadas ou outros segredos no ZIP.
- Mantenha o ZIP original; extraia o conteúdo apenas se o projeto precisar versionar os arquivos individualmente.
